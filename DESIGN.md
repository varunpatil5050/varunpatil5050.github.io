# An orbit of ideas

## Direction

Three concepts were evaluated: full ink-black cinematic luxury; warm editorial
minimalism; and an ivory/ink creative-technology composition with iris accents.
The third preserves the portfolio's original contrast and interactive orbit
while giving technical content the breathing room of the editorial direction.

Warm paper `#f5f3ed`, ink `#1c1b20`, original electric blue `#5068ff`, quiet cool
gray and stone surfaces. The solar panel restores its original lime core
`#c8f75f`, soft blue halo, and blue/lilac/orange/lime orbiting dots. The page
remains ivory; softer green is reserved for selected project surfaces.
Geist provides clarity; Georgia's italic
forms bring a deliberate human contrast. The orbit represents the relationship
between software, intelligence, and product, not an arbitrary particle effect.

## Project palettes

Project-specific materials are maintained in `app/project-palettes.css`:
Atelier uses neutral near-black IDE panels and blue/cream/green syntax;
TransformerLMs uses fresh mint with deep forest ink; Judgment Explained uses
parchment, cocoa and brass. Smaller studies use powder blue, peach-on-ink, and
pale mint. The original solar panel is unchanged. These local palettes vary
the work without recoloring the overall ivory identity.

## Motion system

Primary ease: `cubic-bezier(.16,1,.3,1)`. Feedback 200–400 ms, entrances
750–1200 ms. Native scrolling remains untouched. Passive, frame-coalesced
listeners control page progress, hero field rotation, and restrained
project depth. Reveals run once; featured surfaces also expand gently with
actual scroll progress. Pointer light and small perspective changes
make the project compositions tactile without replacing the cursor.

Atelier has one short sticky story on roomy desktop screens: shared state,
human-approved agent proposals, then replay. It reverses with native scrolling.
Manual controls remain usable; small screens, short windows, and reduced-motion
preferences use the unpinned manual preview. No scrolling is intercepted.

Hero lines shift by at most 13 pixels as the opening leaves the viewport.
Magnetic links move at most four pixels on fine pointers. Native cross-document
view transitions connect project headings where supported, with ordinary
navigation as the fallback and no transition for reduced motion.

The orbit uses transform-only CSS rotation, pauses offscreen, and has an
explicit pause control. Reduced-motion preferences disable movement and reveal
all content immediately. Touch uses static depth and real buttons. No heavy
animation, smooth-scroll, or WebGL dependencies are added.

## Content

Each project has a direct static case-study URL. Illustrative interface/code
previews are labeled, not passed off as screenshots, backend responses, or
model output. Reported metrics retain their evaluation scope. The résumé is the
provided October 2026 file; unsupported adoption claims are excluded.

StreamRank, SignSense, and SyncSpace have keyboard-operable conceptual
architecture explorers. Each stage explains its responsibility, input, and
output. Case studies include chapter navigation and reading progress; technical
copy stays still. Contact exposes the actual email prominently, with a real
clipboard action and an honest fallback if clipboard access is unavailable.

## Reference study

The live Dennis Snellenberg, Cuberto, and Obys homepages were inspected at
desktop size with a scroll sample. The useful common principle was a single
moving focal point surrounded by quiet composition—not a copied template.
The current Obys site differs from its older black kinetic-type reference.
Apple, Lusion, and Bruno Simon were also consulted as references for hierarchy
and meaningful interaction. No reference assets or implementation were copied.
